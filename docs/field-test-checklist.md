# Field Test Checklist — 15 minutes, one phone, outdoors

Do this before calling Phase 1 done and before any public demo.

## Sunlight (Phase 1 exit gate)

- [ ] Open `gallery.html` on a real phone, brightness auto, stand in direct sun.
- [ ] Petrol / CNG / EV pins distinguishable WITHOUT reading? (yes/no)
- [ ] Body text readable at arm's length? (yes/no)
- [ ] If no to either: note which color fails, adjust token, re-test.

## Thumb drive (mobile.html, parked — never while moving)

- [ ] Find → open → navigate to a station in under 30 seconds.
- [ ] Every button reachable with one thumb, no precise aiming.
- [ ] Voice guidance speaks each step (unmuted).

## Honesty

- [ ] "SAMPLE DATA" badge visible on demo + mobile.
- [ ] No price shown without "updated X ago" (or sample badge) next to it.
